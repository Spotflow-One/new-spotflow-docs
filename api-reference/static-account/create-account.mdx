## Adding Test Funds

<Info>
 On test mode with your test keys, you can easily add fake funds to the jollof bank account number created for you using our [Funds Simulator App](https://jollofbank.spotflow.one/). Note that this is for NGN and GHS only. 
  
  See the full guide on [Adding Fake Funds For Testing](/expert-desk/simulating-funds).
