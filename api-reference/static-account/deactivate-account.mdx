---
openapi: /openapi.json DELETE /accounts/{id}/deactivate
title: Deactivate Spotflow Static Virtual Accounts
description: Deactivates a static virtual account, preventing it from receiving any further payments. Once deactivated, the account number can no longer be credited and any incoming transfers to it will be rejected or returned. Use this when a customer's account is closed, when rotating account numbers for security reasons, or when a static account is no longer needed.
---
